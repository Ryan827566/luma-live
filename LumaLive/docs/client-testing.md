# 本机客户端测试

当前活动仓库：`D:\workspace\luma-live`。以下步骤用于开发版验收，不代表模块已全部完成。

## 启动程序

进入 `D:\workspace\luma-live\output\next\Release`：

1. 双击 `luma_signaling_server.exe`，保持服务窗口打开。默认端口是 9000；在服务窗口按回车会关闭服务。
2. 双击 `luma_studio.exe`。本机服务器地址填 `127.0.0.1:9000`。
3. 可以再次启动同一个客户端程序，模拟第二位参与者。每个客户端各自只有一个主窗口；模块通过左侧导航切换。

## 视频通话

两个客户端使用相同房间号、不同成员名，分别加入房间。在一端选择另一成员并呼叫，在另一端接听。确认接通、拒绝、挂断、重新呼叫和离开房间。选择摄像头与麦克风后主动开启设备，检查远端视频和声音。

## 视频会议

一个客户端创建会议，其他客户端使用相同会议号、不同成员名加入。依次检查成员列表、静音、视频关闭/恢复、网格与焦点布局、固定成员、全屏与退出全屏、离开后重入，以及主持人移除成员和结束会议。切换到其他页面再返回，成员和会议应保留。

同一电脑建议戴耳机，仅一个客户端开启摄像头/麦克风，避免设备占用和扬声器回授。单机多进程不能替代双机、NAT/TURN、不同网络和物理设备验收。

## AI

AI 默认关闭，必须先配置并启动 `LumaLive/server/ai-gateway/python/gateway.py`。配置变量见 `session-ai-acceptance.md`；密钥仅放在本机服务进程环境中，不提交到仓库。当前没有真实服务配置，不能声称识别、翻译或朗读的实际质量已验收。

进入对应通话或会议的 AI 页面，启用字幕并告知参与者。转写按约五秒语音片段处理；生成摘要/待办、提取关键词、翻译记录、开启自动翻译均基于当前会话文本。返回视频页面应看到对应成员的原文和译文；字幕十秒过期，停止后清除。点击停止朗读应停止当前播放，并使未返回的语音生成结果失效。已发往服务端的请求无法撤回。

## 自动验证与产物记录

关闭此前手动打开的客户端，再在仓库目录运行：

```powershell
python scripts/windows/verify_client.py
```

脚本使用现有 `build/d-drive` 配置，明确构建 `luma_studio` 可执行目标和测试程序，随后运行 AI 状态、字幕绘制、网关、原生 HTTP、三成员导航和 DPI 回归。只构建 `luma_studio_preview` 会更新静态库，不能据此认定启动程序已更新。不要用 MSBuild OutDir 改写输出目录。

结果写入 `output/client-verification.json`，包含状态、各检查日志路径和被测 EXE 的 SHA-256。报告为 passed 仅代表这些本机自动检查通过；真实 AI、物理设备和最终产品视觉验收仍需单独进行。


注意：统一脚本最后通过 Windows PowerShell 执行 DPI 检查。如果当前系统策略禁止运行 `.ps1`，总报告会保留 failed，前面各项结果仍可查看。这是测试运行条件未满足，不表示 DPI 检查本身已失败；不要把该项当作通过，也不要为了运行测试擅自降低系统执行策略。
