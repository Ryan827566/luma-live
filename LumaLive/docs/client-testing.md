# 本机客户端测试

当前活动仓库：`D:\workspace\luma-live`。以下步骤用于开发版验收，不代表模块已全部完成。

## 启动程序

进入 `D:\workspace\luma-live\output\next\Release`：

1. 双击 `luma_signaling_server.exe`，保持服务窗口打开。默认端口是 9000；在服务窗口按回车会关闭服务。
2. 双击 `luma_studio.exe`。本机服务器地址填 `127.0.0.1:9000`。
3. 可以再次启动同一个客户端程序，模拟第二位参与者。每个客户端各自只有一个主窗口；模块通过左侧导航切换。

## 视频通话

两个客户端使用相同房间号、不同成员名，分别加入房间。在一端选择另一成员并呼叫，在另一端接听。确认接通、拒绝、挂断、重新呼叫和离开房间。选择摄像头与麦克风后主动开启设备，检查远端视频和声音。

## 视频会议

一个客户端创建会议，其他客户端使用相同会议号、不同成员名加入。依次检查成员列表、静音、视频关闭/恢复、网格与焦点布局、固定成员、全屏与退出全屏、离开后重入，以及主持人移除成员和结束会议。切换到其他页面再返回，成员和会议应保留。

同一电脑建议戴耳机，仅一个客户端开启摄像头/麦克风，避免设备占用和扬声器回授。单机多进程不能替代双机、NAT/TURN、不同网络和物理设备验收。

## AI

AI 默认关闭。先打开客户端左侧“AI 助手”，进入“服务设置”，填写服务地址、密钥、语音识别模型以及摘要与翻译模型，然后保存。朗读模型与音色可选，需要成对填写。密钥使用当前 Windows 用户的 DPAPI 加密保存在本机；保存成功不代表真实服务连接已经验证。

在同一页点击“启动本地服务”，无需打开终端或另装 Python。保留 EXE 旁的 `ai-service` 文件夹；缺少运行组件时页面会提示。服务在切页后继续运行，“停止本地服务”或退出拥有它的客户端会关闭它。若检测到另一个程序启动的兼容服务，仅使用该服务，不会擅自关闭它。启动本地服务不会自动开启字幕或上传音频。已有环境变量优先于页面设置，详情见 `session-ai-acceptance.md`。

进入对应通话或会议的 AI“当前会话”页，启用字幕并告知参与者。转写约每五秒按片段处理；可生成摘要与待办、提取关键词、翻译记录或开启自动翻译。“停止朗读”会停止播放并丢弃未返回的朗读结果。真实服务的识别、翻译、延迟和音频质量仍待验收。

有内容后点击“保存记录”，再切换“历史记录”查看。通话和会议的记录各自独立，切换历史记录不会替换正在进行的会话。记录以本地 Markdown 文件保存到 `%LOCALAPPDATA%\LumaLive\records`，不会自动保存音视频，也不会在退出时自动保存会话。新记录需主动点击保存；生成内容仍需人工核对。


## 开发环境打包

首次构建实际 EXE 后运行 `python scripts/windows/package_ai_service.py --download`，脚本从 Python 官方站点下载固定版本、校验 SHA-256 并打包到 EXE 旁的 `ai-service`。后续验证使用已缓存的归档，不会自动下载。分发客户端时须一并保留 `ai-service` 目录及其中的 Python 许可证。

## 自动验证与产物记录

关闭此前手动打开的客户端，再在仓库目录运行：

```powershell
python scripts/windows/verify_client.py
```

脚本使用现有 `build/d-drive` 配置，明确构建 `luma_studio` 可执行目标和测试程序，随后运行 AI 状态、字幕绘制、网关、原生 HTTP、三成员导航和 DPI 回归。只构建 `luma_studio_preview` 会更新静态库，不能据此认定启动程序已更新。不要用 MSBuild OutDir 改写输出目录。

结果写入 `output/client-verification.json`，包含状态、各检查日志路径和被测 EXE 的 SHA-256。报告为 passed 仅代表这些本机自动检查通过；真实 AI、物理设备和最终产品视觉验收仍需单独进行。


DPI 检查现由 `scripts/windows/test_meeting_ui.py` 直接运行原生诊断程序，不再依赖 PowerShell 脚本执行策略，也不修改系统策略。当前支持跟随系统显示语言选择简体中文、繁体中文转换及英文；其它语言仍回退英文，尚不代表完整多语言交付。

界面截图可以运行 `python scripts/windows/capture_studio_ui.py output/next/Release/luma_studio.exe output/ui-visual-review` 生成。脚本仅启动并绘制自己的测试客户端，不截取其它桌面窗口。关闭测试客户端后查看目录中的 calls.bmp、meetings.bmp、assistant.bmp。


在 AI“历史记录”页选择一条记录，点击“删除记录”。确认区域显示在当前页内；Esc、“取消”或切换页面都会取消删除。只有点击“确认删除”才永久删除该条已保存记录，当前会话和另一个工作区的记录不受影响。服务设置中的“检查本地服务”可检查本机网关是否运行、配置是否就绪，不代表真实 AI 模型连接已经验证。
