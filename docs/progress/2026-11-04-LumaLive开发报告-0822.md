## 可运行文件和使用方法

新目录：`D:\workspace\luma-live\output\releases\2026-11-03_23-44-42`。

双击 `Start-LumaLive.cmd` 启动。请保留整个目录，包括 EXE、AI 服务脚本和本地 Python 运行时。此包不包含账户服务器、数据库、真实凭据或测试 fixture。登录仍需要原有账户服务和有效账户。

登录后进入“实时连线”，展开“连接设置”，点击“STUN / TURN”。勾选“启用自定义 STUN / TURN”，填写你可使用的服务器地址，例如 `stun:你的主机:3478`、`turn:你的主机:3478?transport=udp` 或 `turns:你的主机:5349?transport=tcp`。需要认证的 TURN 必须同时填写用户名和密码。

点击“保存”，预期显示“已保存”，新建通话或重新加入会议使用新设置；现有连接保留启动时的配置。重新打开设置应保留填写值，密码以掩码显示。取消、Esc 或关闭窗口不保存未保存的修改。取消勾选并保存后恢复环境默认设置。配置保存在当前 Windows 用户的 `%LOCALAPPDATA%\LumaLive\rtc-network.dat`，整个配置由 Windows DPAPI 加密。

验证输入拒绝时，可暂时填写 `https://invalid.example`，点击保存，应显示格式错误且旧配置不变。该地址只用于验证错误提示，不是可用 STUN 服务。恢复正确配置或取消退出。手工测试如已有配置，应先记录原设置并在测试后恢复，不能把示例服务器当成生产服务。

通过条件：窗口能打开、有效设置能保存并重开、错误输入不能覆盖旧配置、登出后设置窗口关闭。跨网连通性需要两台设备及可用 TURN 服务另行验证，本轮没有验证真实跨网通信。程序使用关闭按钮正常退出，启动脚本随后退出；不需要停止正式服务器。

## 计划 分工和修改范围

原开发 agent rtc_network_store 负责 DPAPI 存储、输入验证和共享 loader；rtc_network_ui 负责 Win32 设置窗口及入口。主 agent 本轮实际应用候选、修正 CMake 编译链接、限制自定义 STUN 为已支持的 `stun:`、构建并运行测试、制作日期包。rtc_resume_acceptance 负责独立审查、修正两处过时测试数据及最终复核。

修改范围为 studio-preview 的 CMakeLists.txt、PreviewNetworkSettings.hpp、PreviewRtcConfig.hpp、NetworkSettingsDialog.hpp、StudioPreview.cpp、两份 C++ 配置测试，以及 scripts/windows/test_rtc_network_settings.py。显式传入的 RTC 配置仍不受用户设置覆盖，断线重连仍使用会话启动快照。没有部署或重启正式账户服务，也没有替换 output/next/Release。

保留用户原有 SVG 和 pycache 改动，不混入代码提交。本次编译基于 main 的 700c1be5 工作树，包含已有 SVG 资源修改，因此不声称二进制来自完全干净的 Git 检出。包内 build-verification.json 记录源码与资源哈希。
